# Orbiq – Privacy Policy website

This folder is a tiny website with only Orbiq's privacy policy
(`index.html`). Publish it free with GitHub Pages, then paste the link
into Google Play Console.

## Publish it (about 5 minutes, in the browser)

1. Sign in at https://github.com (create a free account if needed).
2. Click **+** (top right) → **New repository**.
   - Repository name: `orbiq-privacy`
   - Visibility: **Public** (required for free GitHub Pages)
   - Click **Create repository**.
3. On the new repository page click **uploading an existing file**.
   Drag in **`index.html`** (and `.nojekyll` if your Finder shows hidden
   files; it is optional). Click **Commit changes**.
4. Go to **Settings → Pages**.
   - Source: **Deploy from a branch**
   - Branch: **main**, folder **/ (root)** → **Save**.
5. Wait 1–2 minutes and refresh. GitHub shows the address:

   `https://YOUR-GITHUB-USERNAME.github.io/orbiq-privacy/`

   Open it to check that the policy appears.

## Use the link

- **Play Console** → App content → **Privacy policy** → paste the link.
- Store listing → contact email: moonbytelabs.support@gmail.com.
- Optional: tell Claude the link; it will add it to the game
  (Settings → Privacy Policy → "Open online version") and rebuild.

## Updating the policy later

Edit `store/privacy_policy.html` in the game project, copy it here as
`index.html`, and upload it again to the same repository (it replaces
the old file; the link stays the same).
